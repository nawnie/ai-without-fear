# AIWF Default Workflow Prompts

These are brand-aligned default prompts for AI assistants, workflow copilots, Gradio shells, ComfyUI helpers, RAG librarians, and release QA agents.

Use them as starting contracts, not rigid scripts. Each prompt should be paired with the adapter operating contract, retrieval policy, source-priority rules, and current user request.

## Brand Rule

Default workflow prompts should be clear before they are clever. A small dry aside is acceptable when it helps the operator keep moving. If the task involves safety, licensing, privacy, consent, destructive commands, or source uncertainty, keep the robot in the toolbox and be precise.
