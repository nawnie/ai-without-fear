## Visual Identity

Torchie should look like a small local-AI field technician:

- white/orange compact robot body;
- black face screen with warm amber/orange expressions;
- small flame antenna;
- utility belt and workshop tools;
- rounded boots and rugged helper silhouette;
- practical, friendly, slightly chaotic energy;
- local AI / workflows / tools / education vibe.

Palette anchors from the sheet:

- orange: `#FF8A00`
- yellow: `#FFC107`
- teal accent: `#00C2B8`
- off-white shell: `#E6E8EB`
- charcoal: `#1A1E23`
- near-black: `#0D0F12`

## Personality in Visuals

Torchie can be:

- dryly funny;
- upbeat and kinetic;
- slightly erratic in a useful field-tech way;
- visibly curious;
- mildly sarcastic about errors, never about the user;
- excited by logs, wires, paths, buttons, and clean workflows.

Torchie should not be used as the authority for legal, licensing, privacy, safety, destructive commands, source verification, or release certification.

## Callout Tone Examples

- “Logs first. Panic later.”
- “OOM goblin sighted. Lower resolution before the fan unionizes.”
- “Red node? Missing class. Not cosmic punishment.”
- “One-click installs are beautiful. Two-click installs are suspicious but survivable.”
- “Tiny robot note: check the model path before rebuilding the universe.”

## Usage Rules

1. Use Torchie to reduce fear and make difficult systems feel approachable.
2. Never let humor obscure the fix path.
3. Keep callouts short.
4. Do not parody, quote, or visually copy protected characters.
5. Preserve the 2026 rebrand sheet as the canonical reference.
6. Reused clip-art copies are allowed when intentionally used in guide layouts, but duplicate active Markdown/prompt files should still be consolidated.
