# AIWF Visual Assets

This folder contains reusable visual aids for the AI Without Fear Atlas.

These assets are designed for:

- Field Guide diagrams;
- Gradio app help screens;
- README visuals;
- AI assistant explanations;
- workflow documentation;
- Torchie callouts.

## Indexing Rule

Do not embed raw SVG files by default. Index this README and `VISUAL_ASSET_INDEX.md` instead. Load raw SVGs only when the user asks for diagrams, visual assets, or guide images.

## Asset Types

- `diagrams/svg/` — direct-use vector diagrams.
- `diagrams/mermaid/` — editable Mermaid versions for docs and GitHub rendering.
- `torchie_callouts/` — Torchie visual guidance and callout style sheet.

## Duplicate Policy

Reusable clip art, mascot assets, and exported visual variants may intentionally appear in more than one release or guide folder. Duplicate active Markdown, prompt, schema, and workflow-instruction files should be consolidated or replaced with pointers.


## Torchie 2026 Rebrand

Torchie's active visual identity is now the white/orange workshop robot in `torchie_callouts/torchie_2026_rebrand_reference_sheet.png`. Use the derived crop assets for guide panels, callouts, prompt cards, and UI help. The previous SVG callout sheet has been moved to change history and should not be used for new assets.

Raw SVG diagrams are not indexed by default. The Torchie spec and visual index are the preferred retrieval targets unless the user specifically asks for image assets.
