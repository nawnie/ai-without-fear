# Topic Relationships

Primary relationships:
- Source Ledger supports every other lane through provenance and conflict resolution.
- RAG Architecture supports Atlas cards, chunking, embedding, and evaluation.
- ComfyUI Core API supports workflow JSON/subgraph reasoning.
- Custom Node Ecosystem supports nodepack selection and class_type resolution.
- Pip Runtime supports installation and dependency failure diagnosis.
- CFG/Denoise/Inpaint Theory supports image quality and edit-strength troubleshooting.
- Compatibility Matrix and Failure Signature Atlas should be searched before proposing fixes.
- Workflow Pattern Library bridges user intent to concrete workflow structures.
- Gradio UI Research bridges backend knowledge into local app interfaces.

Future lanes 20-25 should link into RAG Architecture, Evaluation, Deployment/App Architecture, and Failure Signatures once added.
