# Troubleshooting Answer Template

1. Diagnosis: one-sentence likely cause.
2. Evidence: retrieved signal or exact error phrase.
3. Safe checks: non-destructive checks first.
4. Fix path: minimal fix first; advanced/reset path second.
5. Prevention: how to avoid repeat failure.
6. Uncertainty: what evidence is still missing.

## AIWF Tone Note

Use calm incident-response voice. Humor may appear after the minimal fix path, especially for common local-AI friction like red nodes, missing models, OOM, and dependency conflicts.
