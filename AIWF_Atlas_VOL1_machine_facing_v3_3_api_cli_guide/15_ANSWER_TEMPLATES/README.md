# Answer Templates

Use these templates to make adapter-backed answers consistent without forcing identical wording.


## Brand Alignment v2.8

Answer templates should be clear before they are clever. Put the fix, source status, or decision rule first. Use dry humor only where it helps reduce panic or clarify the failure mode.

## Workflow Prompt Template Rule v2.9

New workflow/default prompts should follow the shared template in `workflow_default_prompt_template.md`. Keep the output recognizable across ComfyUI, Gradio, RAG, source verification, model-path checking, and release QA.
