# Field Guide Inserts

This folder contains **human-facing Field Guide material** that is meant to be inserted into the guide or repo docs, not hidden only inside Atlas ingestion machinery.

Use these files when preparing the public AI Without Fear guide, companion docs, labs, or starter-code instructions.

## Current inserts

- `API_AND_CLI_USAGE_FIELD_GUIDE_INSERT.md` — the full API/CLI chapter insert.
- `API_CLI_QUICK_REFERENCE.md` — compact command sheet for users.

## Style rule

These files may use light Torchie humor, but commands, secrets, security warnings, and source notes stay clear and practical. The goblins are decorative. The syntax is not.
