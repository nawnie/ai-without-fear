# Pass 17 Roadmap — Data-Centric ML and Dataset Engineering

**Role in Vol. 2:** This pass sits after statistical learning and architecture, before advanced training methods. It teaches the reader that a training run is only as valid as the dataset contract behind it.

## Teaching sequence

1. Task contract
2. Data inventory and rights review
3. Schema and validation
4. Deduplication and contamination
5. Label/caption quality
6. Split strategy
7. Weak supervision and active learning
8. Synthetic data governance
9. Dataset cards and run packs
10. Drift/skew monitoring

## Reader outcome
By the end of this section, the reader should be able to:

- diagnose whether a dataset is trainable;
- choose a split strategy based on leakage risk;
- write a simple schema/check suite;
- explain why a benchmark score is invalid;
- build a dataset card;
- design a review loop for labels/captions;
- understand why bad data cannot be fixed by a better model alone.
