# 259 — Pass 17 Lab Suite — Make Data Visible

**Pass:** 17  
**Snapshot:** March 2026  
**Layer:** Data-centric ML / dataset engineering / governance  
**Status:** RAG research note

## Labs
1. Build a dataset manifest from a messy folder.
2. Detect exact and near duplicates.
3. Create valid and invalid splits; measure leakage inflation.
4. Write schema tests for JSONL chat data.
5. Generate a dataset card.
6. Use weak supervision rules to label examples.
7. Use active learning to choose review samples.
8. Compare random, stratified, group, and time splits.
9. Run drift comparison between dataset v1 and v2.
10. Package a training run with data fingerprint.

## Outcome
A reader who completes these labs should understand why dataset engineering is not clerical cleanup; it is the core training skill.
