# 245 — Label Quality and Annotator Agreement

**Pass:** 17  
**Snapshot:** March 2026  
**Layer:** Data-centric ML / dataset engineering / governance  
**Status:** RAG research note

## Concept
The label is part of the model. If labels are inconsistent, the model learns inconsistency.

## Label QA methods
- clear label definitions
- gold examples
- disagreement review
- inter-annotator agreement
- confusion matrix by annotator
- label error detection
- abstain/unknown labels

## Generative AI mapping
For image/video LoRAs, captions are labels. For chatbots, assistant responses are labels. For preference training, chosen/rejected pairs are labels.
