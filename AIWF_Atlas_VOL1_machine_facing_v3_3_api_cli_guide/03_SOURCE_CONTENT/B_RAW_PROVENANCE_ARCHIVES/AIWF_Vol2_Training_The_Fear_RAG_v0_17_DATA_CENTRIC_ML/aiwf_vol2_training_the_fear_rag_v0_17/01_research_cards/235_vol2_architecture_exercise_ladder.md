# 235 — Vol. 2 Architecture Exercise Ladder

## Why this matters for Vol. 2
The curriculum needs exercises that turn theory into working judgment without requiring a data-center-scale lab.

## Core facts
- Concept labs: draw architecture/data-flow diagrams.
- Code labs: train tiny MLP/CNN/RNN/transformer toy models.
- Inspection labs: read loss curves and activations.
- Adaptation labs: compare frozen head, LoRA, and full fine-tune.
- Capstone: build a run pack with model card, dataset card, failure memo, and release gate.

## AIWF rules of thumb
- Exercises should scale from CPU/tiny GPU to RTX-class consumer GPUs.
- Every exercise needs expected failure modes and “what to inspect next.”
- The end state is judgment, not just successful execution.

## Exercise / lab hook
Build a 5-week architecture lab sequence that ends with a trained adapter and a release memo.
