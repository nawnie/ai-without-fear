# 253 — Dataset Cards and Governance Cards

**Pass:** 17  
**Snapshot:** March 2026  
**Layer:** Data-centric ML / dataset engineering / governance  
**Status:** RAG research note

## Purpose
A dataset card explains what a dataset is, where it came from, what it should and should not be used for, and what risks remain.

## Required fields
- dataset purpose
- composition
- source/provenance
- collection method
- consent/licensing
- preprocessing
- splits
- known biases
- intended use
- prohibited use
- evaluation notes
- maintenance/removal policy

## AIWF output
Every serious training run should produce a dataset card, even if the dataset never leaves the user’s computer.
