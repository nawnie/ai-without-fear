# Image LoRA Family Rules — Pass 09

1. Do not copy SDXL LoRA settings into FLUX, Qwen-Image, Z-Image, or SD3.5 without a family-specific reason.
2. A trainer saying “supported” does not mean AIWF should recommend it to beginners.
3. SDXL remains the safest first image LoRA lab.
4. FLUX requires explicit VRAM and system RAM warnings.
5. Qwen-Image is advanced/cloud-first until local presets are proven for a user's hardware tier.
6. Z-Image and FLUX.2 Klein are priority March 2026 watch targets for consumer training.
7. Caption policy is part of the model family, not a universal habit.
8. The release gate is visual/prompt-grid behavior, not loss alone.
9. Every trained LoRA needs a release pack with base model, dataset provenance, trainer config, and known limitations.
10. AIWF should build a preset/router layer over existing trainers first.
