# Pass 02M Workflow Policy

## Default rule

Rows added in Pass 02M are **not default workflow-generation rows**. Most are advanced animation, pose, audio, or cache systems with heavyweight dependencies.

## Allowed use

- Use for RAG answers, red-node repair, dependency planning, and capability comparison.
- Use in workflow JSON only after local schema validation and ComfyUI load testing.

## Strong exceptions for future dense passes

- DepthCrafter can become a practical AIWF control-preprocessor path after local testing.
- RyanOnTheInside can become an advanced audio-reactive/temporal-mask chapter after dense schema review.
- Sonic/LatentSync/MuseTalk can be compared for lipsync workflows only in isolated environments.
- TeaCache/MagCache need quality/performance testing before recommendation.

## Hard blocks

- Do not generate from rows marked `needs_retry_or_stale_repo`.
- Do not generate from `search_mapping_hit` rows until source files are fetched and schema-confirmed.
- Do not promote audio/identity/lipsync tools as beginner defaults.
