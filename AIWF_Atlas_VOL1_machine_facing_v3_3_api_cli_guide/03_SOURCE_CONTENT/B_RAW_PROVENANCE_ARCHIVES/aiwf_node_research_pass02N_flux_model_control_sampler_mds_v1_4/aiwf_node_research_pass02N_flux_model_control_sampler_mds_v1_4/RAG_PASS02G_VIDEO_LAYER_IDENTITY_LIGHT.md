# RAG Nodepack Notes — Pass 02G Video / Layer / Identity Packs

## ProPainter

Temporal video inpaint/outpaint. This is not the same as still-image inpainting; it uses frame batches and flow/propagation style settings. Treat as a high-value future workflow target.

## Video Matting

Adds Robust Video Matting and BRIAAI Matting mappings. Useful for alpha/matte workflows and video compositing.

## LayerStyle / LayerStyle Advance

Large dynamic import packs. Valuable for image-editing, compositing, masks, color correction, segmentation, captioning, and VLM-style prompt helpers. Do not generate JSON from module inventory rows without exact class schemas.

## LivePortrait

Face animation / motion retargeting. KJ implementation has sampled schemas for model loading, process, composite, and cropper loading. Identity-sensitive and dependency-heavy.

## InstantID / PuLID / PhotoMaker

Identity/reference-face control families. Use guarded generation only after local InsightFace/ONNX/model testing. Flux variants are base-model-specific and need dense review.
