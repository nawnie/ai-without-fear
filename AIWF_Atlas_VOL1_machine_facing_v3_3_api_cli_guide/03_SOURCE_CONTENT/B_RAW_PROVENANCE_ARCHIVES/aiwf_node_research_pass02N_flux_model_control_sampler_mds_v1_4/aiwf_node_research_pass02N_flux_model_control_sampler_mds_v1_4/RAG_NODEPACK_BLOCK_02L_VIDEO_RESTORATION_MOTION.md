# RAG Nodepack Block 02L — Video Restoration / Motion Support

This block is for broad RAG coverage of high-value support packs, not immediate workflow JSON generation.

## Best use in AIWF

- Use **Frame Interpolation** and **GIMM-VFI** as finishing/comparison knowledge after video generation.
- Use **Old Photos Back to Life** and **InstantIR** as restoration-comparison knowledge for the old-photo chapter.
- Use **Detail Daemon** as an advanced sampler/sigma theory example.
- Use **DynamiCrafter**, **CogVideoX**, **PyramidFlow**, and **FramePack** as legacy/alternate model support notes. They do not replace native Wan 2.2 as the modern-tier default.
- Use **TopazVideoAI** only as an external-app bridge note, because it depends on Topaz Video AI and local ffmpeg paths.

## Workflow generation rules

- Do not generate Topaz workflows as portable defaults.
- Do not generate Old Photos / InstantIR workflows until model download and placement are documented.
- Do not generate VFI workflows until the exact backend target is chosen and schema-checked.
- Do not generate legacy video wrapper workflows unless the goal is explicitly compatibility/comparison.
- Do not generate from retry/stale repo rows.
