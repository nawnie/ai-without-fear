# AIWF RAG Library

This folder holds source-backed AIWF knowledge for local assistant use, Field Manual support, workflow guidance, and future RAG exports.

## Four Topic Lanes

```text
01_comfyui_nodes_and_workflows/
02_python_pip_and_runtime_packages/
03_ml_theory_training_and_model_behavior/
04_agents_rag_local_llm_and_tool_use/
```

## Standard Rule

Every RAG topic lane must keep a `00_SOURCE_LEDGER.md` before producing AIWF cards or retrieval exports.

The source ledger prevents hallucinated certainty, duplicate research, stale claims, and rebuilding projects that already solve the problem.

## Core Files

```text
RAG_DIRECTORY_ARCHITECTURE.md
templates/SOURCE_LEDGER_TEMPLATE.md
templates/AIWF_CARD_TEMPLATE.md
CHANGELOG.md
```

## Output Goal

Turn messy research into clean retrieval-ready knowledge:

```text
source -> clean note -> AIWF card -> JSONL/Markdown export -> assistant answer/workflow guidance
```
