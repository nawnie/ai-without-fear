# Web-Verified Source Pinset — Adapter Evaluation Benchmarking

This pinset supports the AIWF adapter evaluation lane. Use these sources for current claims about RAG/agent evaluation frameworks, metrics, datasets, scorers, and experiment loops.

- **Ragas metrics documentation** — https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/ — RAG and agent evaluation metrics; faithfulness, answer relevance, context precision/recall, and related metric families.
- **MLflow LLM and Agent Evaluation** — https://mlflow.org/docs/latest/genai/eval-monitor/ — Systematic evaluation and monitoring for LLM and agent applications using datasets, scorers, and monitoring loops.
- **DeepEval LLM Evaluation Framework** — https://deepeval.com/ — Open-source LLM evaluation framework with plug-and-play metrics for agents, RAG, and chatbots.
- **DeepEval G-Eval metric documentation** — https://deepeval.com/docs/metrics-llm-evals — LLM-as-judge custom criteria scoring for flexible qualitative evaluation.
- **LangSmith Evaluation documentation** — https://docs.langchain.com/langsmith/evaluation — Evaluation workflow using datasets, evaluators, experiments, human review, code rules, LLM-as-judge, and pairwise comparison.
- **LangSmith evaluation concepts** — https://docs.langchain.com/langsmith/evaluation-concepts — Definitions for datasets, evaluators, online/offline evaluation, and production monitoring concepts.
