# LM Studio Local Server Boundary

LM Studio is an app/runtime/model manager with local APIs, SDKs, REST endpoints, and OpenAI-compatible/Anthropic-compatible routes.

## Support checklist
- Confirm LM Studio app is installed and server is running.
- Confirm port, usually 1234 for OpenAI-compatible examples.
- Confirm selected/loaded model.
- Confirm API base URL, endpoint, and client timeout.
- Separate LM Studio Python SDK issues from LM Studio server issues.

Sources: https://lmstudio.ai/docs/developer/core/server | https://lmstudio.ai/docs/developer/openai-compat | https://lmstudio.ai/docs/python
