# TensorRT package family map

## Standard TensorRT

`tensorrt`, `tensorrt-cu11`, `tensorrt-cu12`, `tensorrt-cu13`, `tensorrt-libs`, `tensorrt-cu12-bindings`, `tensorrt-cu12-libs`, `tensorrt-cu13-bindings`, `tensorrt-cu13-libs`.

## TensorRT lean

`tensorrt-lean`, `tensorrt-lean-cu12`, `tensorrt-lean-cu13`.

## TensorRT-RTX

`tensorrt-rtx`, `tensorrt-rtx-cu12`, `tensorrt-rtx-cu13`, `tensorrt-rtx-cu12-bindings`, `tensorrt-rtx-cu12-libs`, `tensorrt-rtx-cu13-bindings`, `tensorrt-rtx-cu13-libs`.

## TensorRT-LLM

`tensorrt-llm`.

## ONNX support tools

`onnx-graphsurgeon`, `polygraphy`, `onnxslim`.

## PyTorch bridge

`torch-tensorrt`.
