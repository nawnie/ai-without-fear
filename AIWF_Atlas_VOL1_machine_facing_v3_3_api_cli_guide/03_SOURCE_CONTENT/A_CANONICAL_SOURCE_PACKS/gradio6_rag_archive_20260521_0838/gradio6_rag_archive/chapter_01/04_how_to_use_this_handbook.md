# How to Use This Handbook

This handbook is organized progressively:

- **Chapters 1–5**: Foundations and core concepts
- **Chapters 6–9**: Theming, events, state, caching, and security
- **Chapters 10–11**: Deployment and API integration
- **Chapters 12–14**: Custom components, labs, and capstones
- **Chapter 15**: Migration from Gradio 5 and troubleshooting
- **Chapter 16**: Glossary and resources
- **Chapter 17**: Production operations (observability, scaling, testing, etc.)

You can read it sequentially or jump to the sections most relevant to your current needs. The Labs and Capstones chapters are designed for hands-on learning.
