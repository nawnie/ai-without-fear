# Getting Started Recommendations

For the best experience with this handbook:

- If you are new to Gradio → Start with Chapters 1–5
- If you are migrating from Gradio 5 → Focus on Chapter 1 (migration note) and Chapter 15
- If you want to build production apps → Pay special attention to Chapters 10 and 17
- If you prefer hands-on learning → Work through the Labs (Chapter 13) and Capstones (Chapter 14)

You can read sequentially or jump to the topics most relevant to your current project.
