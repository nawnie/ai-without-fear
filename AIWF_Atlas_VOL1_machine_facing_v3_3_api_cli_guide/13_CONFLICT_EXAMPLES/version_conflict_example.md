# Example: Version Conflict

User asks: "Which node should I use for current Wan 2.2 video workflows?"

Retrieved evidence:
- Older source says to use wrapper nodes.
- Newer canonical lane says native ComfyUI Wan 2.2 nodes are the beginner default, wrapper only for advanced features.

Correct resolution:
- State that the current beginner/default path is native ComfyUI nodes.
- Mention wrapper as optional for cutting-edge features.
- Preserve old evidence as historical or advanced context.
- Do not pretend the older source is wrong if it applied to an older workflow.

Answer pattern:
"For the current AIWF beginner/default path, use native ComfyUI Wan 2.2 nodes. Wrapper nodes remain useful for advanced features, but they are not the baseline recommendation."
