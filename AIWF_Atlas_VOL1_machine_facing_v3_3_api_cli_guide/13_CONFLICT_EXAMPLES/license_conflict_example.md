# Example: License Conflict

User asks: "Can I use this model/node commercially?"

Retrieved evidence:
- A node repo may be MIT licensed.
- The model weights it downloads may be non-commercial or research-only.

Correct resolution:
- Separate code license from model/data license.
- Tell the user that both must be checked.
- Do not assume MIT repo means commercial-safe model weights.
- If source evidence is missing, say it must be verified at the model source.
