# Example: Canonical Lane vs Raw Source

Raw source payloads preserve historical information. Canonical research lanes are the AIWF synthesis layer.

When they disagree:
1. Prefer canonical lane for current recommendation.
2. Use raw source for exact quoted/provenance details.
3. Mention version/date/source uncertainty when relevant.
4. Do not delete or ignore historical source context; classify it.

Correct answer posture:
"The source archive contains older guidance, but the canonical lane promotes the newer approach for current builds."
