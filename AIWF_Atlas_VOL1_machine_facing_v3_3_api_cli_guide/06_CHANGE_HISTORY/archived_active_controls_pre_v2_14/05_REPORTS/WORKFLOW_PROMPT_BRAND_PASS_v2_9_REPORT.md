# Workflow Prompt Brand Pass v2.9 Report

## Summary

This pass aligned active workflow prompts, default prompts, and workflow-facing Markdown with the AIWF brand voice while preserving raw source evidence.

## What Changed

- Added workflow prompt/Markdown brand policy.
- Added Torchie personality profile and JSON schema.
- Added a canonical workflow prompt index.
- Added brand-aligned default prompts for ComfyUI, Gradio, RAG ingestion, source verification, model-path checking, and release QA.
- Updated active prompt packs and answer templates with consistent voice rules.
- Added a duplicate-file policy audit that treats visual assets differently from active Markdown/prompt duplicates.

## Torchie Boundary

Torchie is now defined as a non-infringing mascot/helper voice: dry, odd, upbeat, erratic, beginner-reassuring, and useful in warnings or crash explanations. Torchie is not used for legal, licensing, privacy, security, destructive command, or source-verdict content.

## Duplicate Policy

Reusable clip art and visual assets may appear in multiple places when intentional. Active Markdown, default prompts, schemas, and workflow instructions should usually be canonicalized or replaced with pointers.
