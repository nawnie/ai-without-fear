# Session 3: Prompt, Review, Verify

## Purpose

Teach prompting as task specification and verification as part of the same job.

## Learning objectives

- Write a prompt with task, context, audience, constraints, sources, and output format.
- Separate creative generation from factual retrieval.
- Identify claims that need outside verification.
- Improve an output by changing one instruction at a time.

## Facilitator path

1. **Compare two prompts.** Find which instructions make the work easier to review.
2. **Run one guided task.** Use the same approved source material to create a short public draft.
3. **Review in pairs.** Mark altered facts, vague wording, unsupported additions, and missing context.
4. **Change one thing.** Revise one instruction, then compare the result.

## Worksheet prompts

- Write the task, audience, constraints, allowed sources, and output format.
- List the names, dates, numbers, quotes, and links a person must check.
- Record one instruction change and what it changed in the output.

## Leave with

A reusable prompt and review checklist.
