# Session 1: AI Without the Fog Machine

## Purpose

Replace fear, hype, and vague assumptions with a useful mental model.

## Learning objectives

- Describe generative AI as a system that constructs output from learned patterns.
- Separate a fluent response from verified knowledge.
- Name the human responsibilities that remain after AI is introduced.
- Identify low-risk tasks and tasks that need more review.

## Facilitator path

1. **Start with the room.** Ask where AI already touches the work, including built-in and informal use.
2. **Build the mental model.** Walk from input to model and tools, output, then human review.
3. **Sort the work.** Classify example tasks as useful now, needs safeguards, or do not use yet.
4. **Name the decision.** Write down one safe assist, one use to review, and one task to pause.

## Worksheet prompts

- Where may AI already appear in our work?
- What low-risk task might it assist with?
- What task should we pause, and why?

## Leave with

A use, verify, or stop decision rule.
