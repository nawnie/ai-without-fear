# Field Guide to Training Source Map

## Purpose

This file records how the 2026 AI Without Fear Field Manual was transformed into the Community AI Readiness Lab.

The manual is used as a curriculum source, not copied wholesale. Technical detail is translated into transferable decision skills for community organizations.

## Mapping

| Field Guide source | Training use | Transformation |
|---|---|---|
| Foreword and introduction | Program framing | AI as a tool that amplifies human capability; principles transfer across platforms |
| Chapter 02 - terminology without jargon | Session 1 | Keeps plain-language explanations and removes unnecessary architecture detail from the community core |
| Chapter 03 - prompting across models | Session 3 | Converts model-family prompting differences into a general task-specification pattern |
| Chapter 04 - LLM settings | Session 3 and future builder electives | Keeps the lesson that settings affect output; detailed sampling values remain technical-elective material |
| Chapter 05 - Generate -> Select -> Refine -> Finish | Session 6 | Generalizes the production loop into a safe organizational workflow cycle |
| Chapter 05 - seed notebooks and metadata discipline | Sessions 3 and 6 | Converts seed discipline into change-one-variable testing and workflow documentation |
| Chapter 05 - decision trees and troubleshooting matrix | All sessions | Uses symptom -> likely cause -> first fix as the instructional pattern |
| Chapter 06 - temporal consistency and chunking | Future builder electives | Retained for video training, not required in the nonprofit readiness pilot |
| Force Multiplier Insert | Program framing | Human goal, judgment, values, and final decision remain central |

## Visual observations from the PDF

- Pages 1-3 establish a clean field-manual identity with blue rules, restrained typography, and short principle-led framing.
- Page 6 includes a node-workflow image and a ControlNet conditioning diagram. These are useful for a future builder track but too technical for the opening community sessions.
- Pages 21-23 and 31-32 use compact reference tables effectively. The community training should reuse that pattern for data classification, tool decisions, and workflow scoring.
- The later video pages are dense and text-heavy. For live training, those concepts should be broken into cards, diagrams, and exercises rather than projected as manual pages.

## Claims that require current verification before instruction

The following change too quickly to teach from an archived manual without rechecking official sources:

- current model names and availability
- package versions
- hardware recommendations and benchmarks
- API behavior
- privacy, retention, and model-training policies
- software compatibility
- license terms
- active grant opportunities
- legal or regulatory requirements

## Platform rule

New hands-on technical training should use **AIWF Studio as the reference application**. ComfyUI examples in the manual may be used to explain node concepts, workflow provenance, or advanced interoperability, but they are not the default public reference app.

## Content still missing from the Field Guide for this program

The manual is strong on technical production but does not yet contain a complete community-governance curriculum. This training pack adds:

- data classification
- organizational tool review
- human-review requirements
- disclosure decisions
- incident response
- board briefing
- policy drafting
- program evaluation

These additions should eventually become a dedicated AI literacy and governance volume or companion guide rather than being forced into the image/video manual like a policy appendix wearing a fake mustache.
